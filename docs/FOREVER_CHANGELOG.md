# Transmog Hub for WoW Forever — Changelog

## 1.16.2
- The network line at the bottom of the window (outfits still arriving, sending, outfit count) now updates live while the window is open.

## 1.16.1
- **First release for WoW Forever.** Save your look in one click, browse other players' outfits, try them on any race and rate the best — all in game.
- Character names are «First Last», no realm. Players find each other through whispers, groups, guilds and Battle.net friends.
- **Where to find every item**: sources, bosses, quests and coordinates from the AllTheThings database for Forever are built in, no other addons needed.
- Achievements, hidden achievements and tags adapted to Forever.
- English, German, French, Spanish and Russian.

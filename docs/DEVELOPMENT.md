# Transmog Hub — заметки для разработки

Аддон для World of Warcraft (Retail, Midnight): сохраняйте свой трансмог, публикуйте его,
смотрите и примеряйте чужие образы, голосуйте за лучшие.

Сервера нет: наборы и голоса расходятся между игроками через сообщения аддонов
в скрытом канале игры (см. «Сеть»). Стартовое наполнение и «зал славы» приходят
с обновлением аддона в `Data/Bundled.lua`.

## Установка для разработки

Скопируйте (или сделайте симлинк) папку `TransmogHub` в
`World of Warcraft/_retail_/Interface/AddOns/`.

Команды в игре:

| Команда | Что делает |
|---|---|
| `/thub` | открыть или закрыть окно (или кнопка в меню аддонов у миникарты) |
| `/thub test` | создать 25 тестовых наборов в ленте (копии ваших образов со случайным рейтингом) |
| `/thub test clear` | удалить тестовые наборы |
| `/thub capture` | вывести в чат снятый облик (для отладки) |

## Файлы

| Файл | Назначение |
|---|---|
| `Core.lua` | данные, лента, сортировка и фильтры, публикация, голоса, команды |
| `Appearance.lua` | снятие текущего облика, источники вещей, «собрано / не собрано» |
| `Preview.lua` | модель для примерки, смена расы, снятие облика с модели |
| `UI.lua` | главное окно: вкладки, список, примерка, карточка набора |
| `SaveDialog.lua` | окно «Сохранить облик»: название, описание, теги |
| `Achievements.lua` | достижения: список, редкость, статистика, всплывающие уведомления, вкладка |
| `Wowhead.lua` | ссылка на примерочную Wowhead (экспериментально) |
| `Minimap.lua` | кнопка у миникарты |
| `Network.lua` | сеть между игроками: канал, очередь, протокол, синхронизация |
| `Data/Bundled.lua` | подборки наборов, которые выходят вместе с обновлением аддона |

## Формат набора

```lua
{
  id = "n6720b1c4a1f3",         -- id в сети ("n" + uid); у неопубликованных "local:...", у тестовых "test:..."
  name = "Пират с Кровавых Парусов",
  desc = "…",
  author = "Ксарн-Гордунни",
  tags = { "pirate", "c_red" }, -- ключи из TH.TAG_GROUPS в Core.lua
  race = 1, sex = 0,           -- раса и пол автора (sex: 0 муж., 1 жен.)
  class = "ROGUE",
  created = 1760000000,        -- unix time
  -- items[slotID] = { sourceID, secondarySourceID (наплечники), illusionID (оружие) }
  items = { [1] = { 12345 }, [3] = { 23456, 23457 }, [16] = { 34567, nil, 5900 } },
  -- считаются локально по голосам из сети (у подборок могут быть заданы в Bundled.lua):
  rating = { avg = 4.6, n = 123 },
  score = 4.41,                -- для «Лучшие» (байесовское среднее)
  trend = 12.5,                -- для «В тренде»
}
```

## Сеть (`Network.lua`)

**Транспорт.** Все копии аддона заходят в скрытый канал `TransmogHubNet` (он убирается
из окон чата) и шлют `C_ChatInfo.SendAddonMessage` с префиксом `TMHUB`.
Сообщение длиннее 249 байт режется на части: `B<id>…`, `C<id>…`, `E<id>…`
(id — 2 символа base36), короткое уходит как `S…`. Очередь отправки — не чаще
~1 сообщения в секунду; при `InChatMessagingLockdown` (бой, подземелья в Midnight)
отправка ставится на паузу.

**Сообщения** (после сборки; числа в base36, поля через табуляцию):

| Тип | Содержимое | Что делает получатель |
|---|---|---|
| `P` | набор (см. `Net.EncodeSet`) | сохраняет, если такого id нет и он не снят |
| `V` | `id`, звёзды, время | голос отправителя: один персонаж — один голос, новее заменяет старый |
| `W` | `id`, `игрок,звёзды,время;…` | пересланные голоса (при синхронизации, не проверяются) |
| `D` | `id` | снимает набор, **только если отправитель — автор** |
| `H` | версия протокола | «я в сети»; если мы ещё не синхронизированы — запрос `Q` |
| `Q` | `запрос`, `с какого времени` | у кого есть новое — ждёт 1–6 с и отвечает |
| `A` | `запрос` | «я отвечаю»: остальные отменяют свой ответ |

**Синхронизация.** При входе клиент шлёт `Q` со временем прошлой синхронизации
(с часовым запасом). Отвечает один игрок — чья случайная задержка кончилась первой:
`A`, затем до 100 наборов (`P`) и свежие голоса (`W`). Время синхронизации
запоминается, только когда на наш запрос кто-то ответил.

**Доверие.** Имя отправителя гарантирует игра. Подделать можно только пересланные
голоса (`W`) — это осознанное допущение. Своё «скрыть набор» действует только локально.

**Хранение** — `TransmogHubDB.net`: `sets[id]`, `votes[setId][игрок] = {звёзды, время}`,
`tombstones[id]`, `lastSync`. Храним до 3000 наборов, старые вытесняются.
Рейтинг (байесовское среднее) и «В тренде» (сумма звёзд за 7 дней) считаются локально.

## Как устроены примерка и снятие облика

API сверены с исходниками интерфейса клиента 12.1.5 (Gethe/wow-ui-source).

- **Примерка** использует ModelScene со сценой 596, как штатная примерочная (`DressUpFrame`).
  Вещи надеваются через `actor:SetItemTransmogInfo`, поэтому работают раздельные наплечники и иллюзии.
- **Другая раса**: `actor:SetModelByUnit("player", …, customRaceID)`.
  **Пол сменить нельзя**: в 12.x API берёт пол персонажа, а старый `SetCustomRace` удалён.
- **Снятие облика** пробует три способа по очереди:
  1. модель игрока в окне аддона и `actor:GetItemTransmogInfoList()` — то, что реально видно на персонаже
     (так делает штатная примерочная; модель должна быть на экране, иначе не загрузится);
  2. `C_Transmog.GetSlotVisualInfo` — в Midnight отдаёт «просматриваемый» образ, который может
     не совпадать с надетым, поэтому принимается, только если в нём есть наложенный трансмог;
  3. облик надетых вещей без трансмога.

  Команда `/thub capture` покажет, какой способ сработал. Ожидается `model`.

## Примерочная Wowhead

Кнопка «Открыть в Wowhead» выдаёт официальную строку игры `/customset v1 …` — ту же,
что даёт штатная примерочная («Отправить ссылку → Скопировать»). На Wowhead:
Примерочная → Импортировать → «Загрузить через внутриигровую ссылку». Переносятся все слоты,
левый наплечник и иллюзии; расу и пол выбирают на Wowhead. Ту же строку можно вставить в чат
игры — откроется штатная примерочная.

Самодельная ссылка `dressing-room#…` не используется: Wowhead надевает вещи из неё, только если
в ней есть полный блок внешности персонажа, а взять его для произвольной расы аддону негде.

## Что проверить в игре

Аддон прогнан только в заглушке игрового API, в живом клиенте он ещё не запускался.

1. `/thub capture` пишет `способом: model` и выдаёт ID по слотам, совпадающие с трансмогом.
2. Модель в окне видна, правильно кадрирована, вращается мышью.
3. Смена расы в примерке работает, вещи после смены надеваются заново.
4. В карточке набора видны названия вещей, источники и отметки «собрано».
5. Харанир (новая раса Midnight) — добавить её raceID в `RACE_IDS` в `Preview.lua`.

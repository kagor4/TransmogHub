# Transmog Hub for WoW Forever — Changelog

## 1.16.7
- Fairer ratings: votes from players who consistently rate far below everyone else and have no published outfits of their own count for less. The more such votes and the bigger the gap, the smaller their weight; publishing outfits or rating closer to others restores it.

## 1.16.6
- Tidier layout: the top buttons and the search box line up with the panels below; the search box stretches to the nearest button (also on the Achievements tab); equal gaps between the Achievements buttons; the ranking controls line up with the buttons above them.

## 1.16.5
- Rating notifications no longer show how many stars the player gave — only who rated your outfit.
- Where to find: fresh AllTheThings database for Forever.

## 1.16.4
- Cyrillic player names no longer show as empty squares on English, German, French and Spanish clients when the addon uses the game font.
- Settings: the Blizzard window style is now called «Game default» instead of «Common».

## 1.16.3
- Maintenance update.

## 1.16.2
- The network line at the bottom of the window (outfits still arriving, sending, outfit count) now updates live while the window is open.

## 1.16.1
- **First release for WoW Forever.** Save your look in one click, browse other players' outfits, try them on any race and rate the best — all in game.
- Character names are «First Last», no realm. Players find each other through whispers, groups, guilds and Battle.net friends.
- **Where to find every item**: sources, bosses, quests and coordinates from the AllTheThings database for Forever are built in, no other addons needed.
- Achievements, hidden achievements and tags adapted to Forever.
- English, German, French, Spanish and Russian.

# Transmog Hub — заметки для разработки

Аддон для World of Warcraft (Retail, Midnight): сохраняйте свой трансмог, публикуйте его,
смотрите и примеряйте чужие образы, голосуйте за лучшие.

Сервера нет: образы и голоса расходятся между игроками через сообщения аддонов
в скрытом канале игры (см. «Сеть»). Стартовое наполнение и «зал славы» приходят
с обновлением аддона в `Data/Bundled.lua`.

## Установка для разработки

Скопируйте (или сделайте симлинк) папку `TransmogHub` в
`World of Warcraft/_retail_/Interface/AddOns/`.

Команды в игре:

| Команда | Что делает |
|---|---|
| `/thub` | открыть или закрыть окно (или кнопка в меню аддонов у миникарты) |
| `/thub test` | создать 25 тестовых образов в ленте (копии ваших образов со случайным рейтингом) |
| `/thub test clear` | удалить тестовые образы |
| `/thub capture` | вывести в чат снятый облик (для отладки) |

## Файлы

| Файл | Назначение |
|---|---|
| `Core.lua` | данные, лента, сортировка и фильтры, публикация, голоса, команды |
| `Appearance.lua` | снятие текущего облика, источники вещей, «собрано / не собрано» |
| `Preview.lua` | модель для примерки, смена расы, снятие облика с модели |
| `UI.lua` | главное окно: вкладки, список, примерка, карточка образа |
| `SaveDialog.lua` | окно «Новый образ»: название, описание, теги |
| `Achievements.lua` | достижения: список, редкость, статистика, всплывающие уведомления, вкладка |
| `Wowhead.lua` | строка `/customset` для примерочной Wowhead, ссылки на вещи |
| `Minimap.lua` | кнопка у миникарты |
| `Moderation.lua` | фильтр названий и описаний: фильтр Blizzard + свой список корней, ссылки и реклама |
| `Network.lua` | сеть между игроками: канал, очередь, протокол, синхронизация |
| `Data/Bundled.lua` | подборки образов, которые выходят вместе с обновлением аддона |

## Формат образа

```lua
{
  id = "n6720b1c4a1f3",         -- id в сети ("n" + uid); у неопубликованных "local:...", у тестовых "test:..."
  name = "Пират с Кровавых Парусов",
  desc = "…",
  author = "Ксарн-Гордунни",
  tags = { "pirate", "c_red" }, -- ключи из TH.TAG_GROUPS в Core.lua
  race = 1, sex = 0,           -- раса и пол автора (sex: 0 муж., 1 жен.)
  class = "ROGUE",
  created = 1760000000,        -- unix time
  -- items[slotID] = { sourceID, secondarySourceID (наплечники), illusionID (оружие) }
  items = { [1] = { 12345 }, [3] = { 23456, 23457 }, [16] = { 34567, nil, 5900 } },
  -- считаются локально по голосам из сети (у подборок могут быть заданы в Bundled.lua):
  rating = { avg = 4.6, n = 123 },
  score = 4.41,                -- для «Лучшие» (байесовское среднее)
  trend = 12.5,                -- для «В тренде»
}
```

## Сеть (`Network.lua`)

**Транспорт.** Пять каналов связи, все через сообщения аддонов с префиксом `TMHUB`:

| Канал | Кого достаёт | API |
|---|---|---|
| скрытый канал `TransmogHubNet` (убирается из окон чата) | игроков своего сервера | `C_ChatInfo.SendAddonMessage(…, "CHANNEL", номер)` |
| группа или рейд — только если в ней есть игроки с других серверов | группу, через серверы и фракции | `SendAddonMessage(…, "PARTY"/"RAID"/"INSTANCE_CHAT")` |
| друзья Battle.net в WoW Retail | друзей на любом сервере и в любой фракции | `C_BattleNet.SendGameData`, событие `BN_CHAT_MSG_ADDON` |
| гильдия — знакомство и синхронизация при входе; рассылка, если через гильдию слышно тех, кого нет в канале | согильдийцев другой фракции (и всех согильдийцев в Forever, где канал у каждого свой) | `SendAddonMessage(…, "GUILD")` |
| скрытый шёпот — «знакомство через каталог»: одиночка без связей раз в 5 минут стучится (`H`) к трём недавним авторам своей фракции из базы и каталога, к каждому не чаще раза в сутки; ответившие получают всю рассылку | игроков своей фракции на других серверах | `SendAddonMessage(…, "WHISPER", имя)`; «игрок не найден» скрыт фильтром `CHAT_MSG_SYSTEM` |
| скрытый шёпот — знакомые: кого слышали шёпотом, помним между сессиями (50, 30 дней) и после входа стучимся к ним; при знакомстве обмениваемся 5 контактами (`k`); стучимся и к тем, с кем переписывались или были в группе (14 дней). Не больше 3 стуков за раз, 20 за сессию, к каждому раз в сутки; рассылка — 8 самых недавних знакомых. Новичок (до 7 дней, `w` — дата установки) из собеседников засчитывается приглашённым | игроков на любых серверах своей фракции | `SendAddonMessage(…, "WHISPER", имя)` |

Кроме сети, образы приходят **каталогом** с обновлением аддона (`Data/Bundled.lua`, собирает
ежедневный выпуск): их видно и там, где рядом никого с аддоном.

Сообщение длиннее 249 байт режется на части: `B<id>…`, `C<id>…`, `E<id>…`
(id — 2 символа base36), короткое уходит как `S…`. Очередь отправки общая — не чаще
~1 сообщения в секунду; при `InChatMessagingLockdown` (бой, подземелья в Midnight)
отправка ставится на паузу.

**Мосты между серверами.** Новый образ или голос, пришедший по одному каналу связи,
пересылается в остальные (кроме того, откуда пришёл). Повторы отсекаются: образ с
известным id не сохраняется и дальше не идёт. Голос при пересылке превращается в `W`
с именем проголосовавшего. Если очередь длиннее 200 сообщений, пересылка пропускается —
недостающее догонит синхронизация. Удаление (`D`) не пересылается: автор сам рассылает
его по всем своим каналам связи.

**Сообщения** (после сборки; числа в base36, поля через табуляцию):

| Тип | Содержимое | Что делает получатель |
|---|---|---|
| `P` | образ (см. `Net.EncodeSet`) | сохраняет, если такого id нет и он не снят |
| `V` | `id`, звёзды, время | голос отправителя: один персонаж — один голос, новее заменяет старый |
| `W` | `id`, `игрок,звёзды,время;…` | пересланные голоса (при синхронизации, не проверяются) |
| `D` | `id` | снимает образ, **только если отправитель — автор** |
| `H` | версия протокола | «я в сети». Канал: если не синхронизированы — запрос `Q`, в маленькой сети ответ `I`. Друг Battle.net или группа: ответ `I` |
| `I` | версия протокола | «я тоже тут». От друга Battle.net — запрос `Q` ему напрямую |
| `Q` | `запрос`, `с какого времени` | канал и группа: у кого есть новое — ждёт 1–6 с и отвечает; другу Battle.net отвечаем сразу и напрямую |
| `A` | `запрос` | «я отвечаю» (старый `Q`) или «синхронизировано» (после ответа на `r`) |
| `q` | `запрос`, `с какого времени` | быстрая синхронизация: у кого есть новое — предложение `o` (в канале, группе, гильдии — до трёх игроков) |
| `o` | `запрос`, отпечатки через запятую | что у игрока есть (до 600 образов, новые первыми). Отпечаток — хеш id, до 6 знаков |
| `r` | `запрос`, `кому`, `с какого времени`, отпечатки | «пришли эти»; `кому` = `*` — любой, у кого есть. Указано время — ещё голоса и прочее, в конце `A` |
| `b` | образ в сжатом виде | ответ на `r`, вне очереди; дальше пересылается обычным `P` |

**Синхронизация.** При входе клиент шлёт `q` со временем прошлой синхронизации (с часовым
запасом; в первый раз — с выпуска каталога из обновления минус двое суток). Игроки отвечают
списком отпечатков `o`; клиент сверяет его со своей базой и каталогом и просит `r` только
недостающее, деля его между предложившими (у каждого свой лимит отправки). Первый
предложивший присылает ещё голоса и прочее и закрывает `A`. Если за 10 секунд никто не
предложил (старые версии не знают `q`), уходит старый `Q`: отвечает один игрок — `A`,
до 100 образов (`P`) и свежие голоса (`W`). Время синхронизации запоминается, только когда
на наш запрос кто-то ответил. Ссылка из чата на отсутствующий образ — сразу `r` с `*`.

**Доверие.** Имя отправителя гарантирует игра. Подделать можно только пересланные
голоса (`W`) — это осознанное допущение. Своё «скрыть образ» действует только локально.

**Хранение** — `TransmogHubDB.net`: `sets[id]`, `votes[setId][игрок] = {звёзды, время}`,
`tombstones[id]`, `lastSync` (канал), `peerSync[друг]` (время синхронизации с каждым другом). Храним до 3000 образов, старые вытесняются.
Рейтинг (байесовское среднее) и «В тренде» (сумма звёзд за `TH.TREND_DAYS` = 30 дней) считаются локально. «Новые» показывают образы за `TH.NEW_DAYS` = 60 дней.

## Где найти вещь: встроенная база (`TransmogHub_Sources`)

Источники вещей с обликами взяты из базы [AllTheThings](https://github.com/ATTWoWAddon/AllTheThings)
(лицензия MIT, текст — в `TransmogHub_Sources/LICENSE-AllTheThings.txt`). Это отдельный аддон
в той же сборке (`move-folders` в `.pkgmeta`), загружается по требованию: Transmog Hub
подгружает его через 20 секунд после входа или при первой подсказке. Около 93 тысяч вещей,
файл ~4 МБ, в памяти ~6 МБ.

Запись вещи — до 4 источников: `раздел|место|источник|карта:x:y|цена`. Названия мест, боссов,
заданий и существ игра даёт сама на языке клиента; названия заголовков и объектов ATT
лежат в файле на ruRU/enUS/esES.

Обновить базу (раз в неделю–две, ATT часто дополняется):

```
tools/att/update.sh
```

Скрипт скачивает базу ATT (только `db/Standard`) и пересобирает `TransmogHub_Sources/ATT.lua`
через `tools/att/build.lua`. Проверка сборщика на образце: `lua5.1 tests/att.lua .`

Порядок в подсказке: установленный AllTheThings (его живая база), встроенная база, находки игроков.

## Как устроены примерка и снятие облика

API сверены с исходниками интерфейса клиента 12.1.5 (Gethe/wow-ui-source).

- **Примерка** использует ModelScene со сценой 596, как штатная примерочная (`DressUpFrame`).
  Вещи надеваются через `actor:SetItemTransmogInfo`, поэтому работают раздельные наплечники и иллюзии.
- **Другая раса**: `actor:SetModelByUnit("player", …, customRaceID)`.
  **Пол сменить нельзя**: в 12.x API берёт пол персонажа, а старый `SetCustomRace` удалён.
- **Снятие облика** пробует три способа по очереди:
  1. модель игрока в окне аддона и `actor:GetItemTransmogInfoList()` — то, что реально видно на персонаже
     (так делает штатная примерочная; модель должна быть на экране, иначе не загрузится);
  2. `C_Transmog.GetSlotVisualInfo` — в Midnight отдаёт «просматриваемый» образ, который может
     не совпадать с надетым, поэтому принимается, только если в нём есть наложенный трансмог;
  3. облик надетых вещей без трансмога.

  Команда `/thub capture` покажет, какой способ сработал. Ожидается `model`.

## Примерочная Wowhead

Кнопка «Открыть в Wowhead» выдаёт официальную строку игры `/customset v1 …` — ту же,
что даёт штатная примерочная («Отправить ссылку → Скопировать»). На Wowhead:
Примерочная → Импортировать → «Загрузить через внутриигровую ссылку». Переносятся все слоты,
левый наплечник и иллюзии; расу и пол выбирают на Wowhead. Ту же строку можно вставить в чат
игры — откроется штатная примерочная.

Самодельная ссылка `dressing-room#…` не используется: Wowhead надевает вещи из неё, только если
в ней есть полный блок внешности персонажа, а взять его для произвольной расы аддону негде.

## Что проверить в игре

Аддон прогнан только в заглушке игрового API, в живом клиенте он ещё не запускался.

1. `/thub capture` пишет `способом: model` и выдаёт ID по слотам, совпадающие с трансмогом.
2. Модель в окне видна, правильно кадрирована, вращается мышью.
3. Смена расы в примерке работает, вещи после смены надеваются заново.
4. В карточке образа видны названия вещей, источники и отметки «собрано».
5. Харанир (новая раса Midnight) — добавить её raceID в `RACE_IDS` в `Preview.lua`.
